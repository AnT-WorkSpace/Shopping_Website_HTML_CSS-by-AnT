# Amazon Website Clone & HTML/CSS Handwritten Study Notes by AnT

## 👤 Author
* **Created by:** Ankit-Thakur(AnT)
* **Goal:** Mini-project using HTML and CSS for fundamental understanding of frontend.
---

A responsive frontend miniproject recreating the layout and styling of the Amazon homepage using pure **HTML5** and **CSS3**. This repository also serves as a reference workspace containing practical handwritten study notes on web development fundamentals.

## 🚀 Features
* **Amazon UI Replica:** Navigation bar, hero banner section, product display grid, and footer.
* **Pure HTML & CSS:** Built without external frameworks to practice core layout mechanics.
* **Handwritten Study Notes:** Structured notes detailing HTML semantics, the CSS Box Model, and Flexbox positioning.

## 🛠️ Built With
* **HTML5** — Semantic page markup
* **CSS3** — Flexbox layout & custom styling
* **VS Code** — Code editor on macOS
